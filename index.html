Personal-use OAuth integration

rclone-nuc

rclone-nuc is a personal, non-commercial integration that uses rclone and the Google Drive API to back up and restore files from a self-managed computer.

Purpose

The application is intended for the owner's own Google account. It authorizes rclone to transfer backup files to Google Drive and, when needed, retrieve or manage those files.

How it works

Google OAuth 2.0 is used to obtain authorization from the account owner. File transfers are performed by rclone on the owner's machine. This website is informational only: it has no sign-in form and does not receive Google Drive files or OAuth tokens.
